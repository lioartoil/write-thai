# write-thai

Thai prose refinement skill for Claude Code.

## Structure

```
skills/write/
  SKILL.md          - Skill definition and trigger
  references/
    write-th.md     - Thai prose refinement rules
```

## Usage

Install with: `npx skills add lioartoil/write-thai -a claude-code -g -y`

Then use `/write` when editing Thai prose.
