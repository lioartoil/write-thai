## Thai Prose Refinement

> Sources: Waza write-zh.md methodology, TCI-THAIJO translation error taxonomy (51% word-choice, 40% connective errors), Pantip native speaker feedback ("ภาษาแข็งๆ แปลกๆ", "ไม่เนียน", "ภาษาโรบอท"), UX localization research (Medium). Books for enrichment: ทฤษฎีและหลักการแปล (Chula Press), หลักการแปล (SE-ED), PSU MOOC เทคนิคการแปล.

ตัดสำนวน AI ออก เขียนให้เหมือนคนไทยพูดกับคนไทย ไม่ใช่ภาษาแปล

### ลำดับการแก้ (ทำตามลำดับ)

1. **รักษาความหมาย** — ข้อเท็จจริง ตรรกะ เหตุผล ต้องไม่เปลี่ยน
2. **ตัด AI ออก** — ลบประโยคสรุปท้ายย่อหน้า ลบสำนวนแปล ลบคำฟุ่มเฟือย **ตรวจประโยคสรุปท้ายย่อหน้าก่อน** ("จะเห็นได้ว่า", "กล่าวได้ว่า", "สรุปแล้ว") — นี่คือร่องรอย AI ที่พบบ่อยที่สุด
3. **ปรับให้ลื่น** — แก้ประโยคที่อ่านแล้วสะดุด ตัดคำเชื่อมที่ไม่จำเป็น
4. **ตรวจอักขระ** — เว้นวรรค ไม้ยมก ทัณฑฆาต
5. **อ่านทวนทั้งหมด** — แก้จุดที่สะดุด ไม่ต้องเปลี่ยนประโยคที่อ่านแล้วเป็นธรรมชาติอยู่แล้ว

### สำคัญที่สุด: เป็นธรรมชาติ > มีสไตล์

ไม่ต้องเพิ่มคำพูดแบบ chat เข้าไปเพื่อให้ดู "เหมือนคนเขียน" ถ้าประโยคอ่านแล้วเรียบ ชัด ไม่สะดุด ไม่ต้องแก้

### โครงสร้างภาษาแปลที่ต้องตัด

สำนวนที่ "แปลมาจากอังกฤษ" — อ่านแล้วรู้ทันทีว่าไม่ใช่ภาษาไทยแท้:

| NO: ภาษาแปล | OK: ภาษาไทย |
|------------|------------|
| ในการที่จะ | เพื่อ / ถ้าจะ |
| มันเป็นสิ่งสำคัญที่ | สำคัญคือ / ต้อง |
| สิ่งที่ควรจะถูกพิจารณา | ต้องดู / ต้องคิด |
| ได้รับการยืนยันแล้วว่า | ยืนยันแล้วว่า |
| ถูกออกแบบมาเพื่อ | ออกแบบมาเพื่อ |
| มีความสามารถในการ | ทำ...ได้ |
| เป็นที่ทราบกันดีว่า | — (ตัดออก พูดเรื่องเลย) |
| ในบริบทของ | — (ตัดออก) |
| เมื่อเทียบกับ...แล้ว | กว่า / มากกว่า |

**Nested ซึ่ง/ที่**: ประโยคยาวที่มี "ซึ่ง...ที่...ซึ่ง..." ซ้อนกัน ให้ตัดเป็นประโยคสั้นๆ หลายประโยค

**Passive ถูก overuse**: ภาษาไทยใช้ "ถูก" น้อยกว่าอังกฤษมาก ถ้าเปลี่ยนเป็น active ได้ ให้เปลี่ยน
> NO: "ระบบถูกพัฒนาขึ้นมาเพื่อ"
> OK: "ทีมพัฒนาระบบนี้เพื่อ" หรือ "ระบบนี้สร้างมาเพื่อ"

### ครับ/ค่ะ และ particles

**ไม่ใส่ ครับ/ค่ะ ในบทความ** — บทความไม่ต้องมี particles ยกเว้นเป็นบทสนทนาหรือ chat

**ถ้าเป็น chat/message**:
- ใช้ ครับ สำหรับผู้ชาย, ค่ะ สำหรับผู้หญิง — ห้ามสลับ
- คำถามใช้ ไหมครับ/คะ ไม่ใช่ ไหมค่ะ (ค่ะ = ตอบ, คะ = ถาม)
- ไม่ต้องใส่ทุกประโยค — ใส่ท้ายข้อความหรือจุดสำคัญพอ

**Casual particles ที่ AI มักไม่ใส่ (แต่คนไทยใช้)**:
- นะ (softener) — "ลองดูนะ" ไม่ใช่ "กรุณาลองดู"
- สิ (encouragement) — "ลองสิ"
- เลย (emphasis) — "ทำเลย"
- ล่ะ (casual question) — "ยังไงล่ะ"
- ครับ/ค่ะ ตอนจบเท่านั้น ไม่ใช่ทุกประโยค

### สรรพนาม

**ภาษาไทยตัดสรรพนามได้** — AI มักใส่ ผม/ฉัน/เรา ทุกประโยค คนไทยไม่ทำแบบนั้น

> NO: "ผมคิดว่าผมควรจะลองดู เพราะผมเห็นว่าผมยังไม่เข้าใจ"
> OK: "คิดว่าน่าจะลองดู เพราะยังไม่ค่อยเข้าใจ"

**เลือกสรรพนามตาม context**:
- บทความ: ไม่ต้องมี / "เรา" (inclusive)
- Tech writing: "เรา" หรือตัดออก
- Chat กับหัวหน้า: "ผม" + ครับ
- Chat กับเพื่อน: ตัดออก / "กู" (ถ้าสนิทมาก)

### โครงสร้างประโยคที่ต้องหลีกเลี่ยง

**สรุปท้ายย่อหน้า** (ร่องรอย AI อันดับ 1):
> NO: "จะเห็นได้ว่า ระบบนี้มีประสิทธิภาพสูง"
> NO: "กล่าวโดยสรุป ..."
> NO: "ดังนั้น จึงสรุปได้ว่า ..."
> OK: ตัดออก ให้ข้อมูลพูดแทน

**List 3 ข้อเสมอ**: AI ชอบทำ list 3 ข้อ ถ้ามี 2 ก็พอ ถ้ามี 4 ก็ใส่ 4

**ขึ้นต้นซ้ำ**: "ประการแรก... ประการที่สอง... ประการที่สาม..." — ใช้ได้ถ้าเป็นขั้นตอน แต่ถ้าเป็นการอธิบายให้เขียนเป็น prose

**คำถาม rhetorical**:
> NO: "แล้วเราควรทำอย่างไร? คำตอบคือ..."
> OK: พูดคำตอบเลย

**เปิดด้วย "ในยุคปัจจุบัน"**:
> NO: "ในยุคปัจจุบันที่เทคโนโลยี AI ..."
> OK: เข้าเรื่องเลย — "Claude Code ช่วยให้..."
